# FS (File System)

it direct connect with client OS rater than browser

## Major task of FS Module

- Reading and writing files
  - readFile()
  - writeFile()
  - appendFile()
- Directory Management
  - mkdir()
  - rmdir() - depricated
  - rm()
  - readdir()

- Metadata/Information
  - stat()
  - lstat()
  - fstat()
- watching for Changes
  - watch()
  - watchFile()
  - unwatchFile()
- Streaming Large File
  - createReadStream()
  - CreateWriteStream()
- File Operations
  - rename () 
  - truncate()
  - unlink()
  - link()
  - syslink()
